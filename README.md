# Gerenciador de Estoques — interface

Protótipo de interface web para gestão de estoque. O projeto apresenta telas de painel, produtos, classes, movimentações, unidades e usuários. Os dados atuais são demonstrativos e mantidos no próprio front-end; não há integração com backend neste repositório.

## Executar localmente

Requer Node.js e npm.

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
npm run preview
```

## Tecnologias

React, TypeScript e Vite. O projeto mantém `package-lock.json`; use npm para instalar dependências.
